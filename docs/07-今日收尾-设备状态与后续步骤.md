## 二、烧录方法（已完全掌握，可复用）

```
1) 底板彻底断电（USB + 独立电源）
2) 将 BOOT_MODE（管脚 82，板上可能标 KEYOUT1）短接到 GND 并保持
3) 保持短接状态下上电，1~2 秒后松开
4) 电脑执行：
   <ABOOT_TOOLS>\adownload.exe \
       -u -a -r -q -s 115200 <固件包.zip>
```

- 工具会认到 `Arom Usb Boot Port` / `ASR Serial Download Device (COM5)`，约 26~28 秒写完
- **不要加 `-m`**（production 模式会擦 `factory` 分区，可能丢 IMEI）
- 依据：《ML307A 硬件设计手册（OpenCPU 版）》3.15.3 下载控制接口；
  `RESET`(15) 只是复位脚，**不是**下载 strap（实测无效）

## 四、待解决问题

### 4.1 网络注册失败（优先级最高）

```
AT+CGDCONT?  -> +CGDCONT: 1,"IPV4V6","",,0,0,,,,   ← APN 被 nvm 擦除清空
AT+COPS?     -> +COPS: 0                            ← 无运营商
AT+CEREG?    -> +CEREG: 0,0                         ← 未注册
AT+CGACT?    -> +CGACT: 1,0 / 8,0                   ← PDP 未激活
AT+CGACT=1,1 -> +CME ERROR: 100                     ← 因未注册而失败
AT+CSQ       -> +CSQ: 31,99                         ← 信号良好
```

已做：写入 `AT+CGDCONT=1,"IPV4V6","cmnet"` 与 `AT+CGDCONT=8,"IPV4V6","IMS"`、
`AT+MDIALUPCFG="auto",1`（中移自动拨号）→ 仍未注册。

**下一步要做的判定**（今天这步因权限审批被中止，未执行）：

```
AT+COPS=?            → 能否扫到运营商？能扫到 = 射频收发正常；扫不到 = 射频校准可能丢失
AT*MRD_CalInfo?      → 查看校准信息是否还在
AT+CFUN=1 后等待 60s → 注册有时较慢
```

**若确认为射频校准丢失**：整包烧录写了通用 `rf.bin` 且擦了 `nvm`，而**每台模组的射频校准数据是产测时写入的**。
需要向中移 FAE 索取：① 出厂 AT 固件包 ② 产测/校准恢复流程（工具 CATStudio，
Gitee 有 `CATStudio_V3_0_7_82.zip`）。

### 4.2 应用崩溃缺陷（已定位到大方向，未定位到行）

回退实验证明崩溃在我的应用里。尚未排除的可疑点（按可能性排序）：

1. **入口未调用 `uart_open(CM_UART_DEV_0, 921600, u0_callback)`**
   SDK 官方入口第一件事就是打开 UART0，`app.c` 注释明确："串口由于 LOG 功能，
   已在 `cm_opencpu_entry()` 开头初始化"。本应用未打开即调用 `cm_log_printf()`。
2. **`get_rx_byte_all()` / `get_tx_byte_all()`**（流量统计）—— 未文档化的平台计数器。
3. **应用 BSS 100,976B**（基线仅约 880B）—— 需确认 `app_dsln.ld` 的 RAM 区完整归应用使用。

**最有效的下一步**：接 **DBG_UART**（管脚 17/18，921600）抓启动日志，
一次就能看到崩溃的确切位置。需要 USB-TTL 模块（串口转 USB）。

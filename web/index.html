帮助

📡 仪表盘

显示 ML307A 模块的实时状态：信号强度、运营商、网络状态、IMEI、短信总数。

自动每 5 秒刷新，绿灯表示运行中，黄灯表示已连接(未轮询)，红灯表示未连接。

📤 验证码转发

过滤模式：

  • 白名单：只转发含有关键词的短信
  • 黑名单：排除含有关键词的短信，其余全部转发
  • 全部转发：不筛选，所有短信都转发

转发模板：

  • 默认：发送方号码 + 时间 + 完整内容(200字)
  • 精简：自动提取验证码，如 "【1069xxx】验证码: 123456"
  • 仅验证码：只发纯数字验证码，如 "【1069xxx】123456"

Webhook 配置：支持钉钉机器人（关键词模式 / 签名模式）和企业微信机器人。

钉钉关键词模式需要在机器人和应用内设置相同的关键词（默认为"短信"）。

💬 短信记录

展示所有接收到的短信，支持搜索。鼠标悬停可看到删除按钮(×)，点击可删除该条短信。

时间戳格式为 ISO 8601，转换为本地时间显示（刚刚/分钟前/小时前/完整日期）。

✉️ 发送短信

通过 ML307A 模块发送短信。输入手机号码和短信内容，点击发送。

字符计数右侧显示当前已输入字符数/70（单条短信最大长度）。

📞 拨号盘

通过 ML307A 模块拨打电话。输入号码后点击"拨打"，通话记录会自动保存。

点击"挂断"结束当前通话。每次拨打后会显示上次拨打记录。

📋 通话记录

显示最近 50 条通话记录，包括拨打时间、号码、通话类型（↑拨出）。

记录存储在内存中，重启服务后清空。

📖 电话本

ML307A 模块 SIM 卡电话本管理。可查看、添加联系人。

添加时填写姓名和电话号码，点击"添加"即可存入模块。

🔧 设备诊断

平台信息：当前运行的操作系统和架构。

驱动绑定：(仅 Linux) 一键绑定 ML307A USB 驱动，使模块被正确识别。

设备信息：信号、网络、IMEI、运营商、SIM 卡 IMSI、模块时间。

⚙️ 设置

配置管理：导出/导入 JSON 配置文件，或重置为默认值。

串口设置：设置 ML307A 的串口端口（默认为 auto，自动检测）和波特率（默认 115200）。

轮询间隔：短信检测间隔，默认 1 秒。值越小转发越快，但对模块压力越大。

🚀 自启动

设置开机自动启动短信转发器。

  • Linux：创建 XDG Autostart .desktop 文件
  • macOS：创建 LaunchAgent plist 文件
  • Windows：写入注册表 Run 键

🖥️ 系统托盘

右键/左键点击右下角绿色气泡图标：

  • 打开主界面：浏览器打开管理页面
  • 开机自启动：勾选后开机自动运行
  • 重启应用：结束所有进程并重新启动
  • 退出程序：关闭短信转发器

双击可执行文件：如服务已在运行则打开浏览器，否则启动服务。

（macOS/Windows 需原生 CGO 编译才有托盘）

📝 日志

显示最近的系统日志（最多 500 条），包括连接、短信过滤/转发、错误等信息。

每 3 秒自动刷新。
